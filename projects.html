Featured · Individual project

Sales Prediction with Multiple Linear Regression

A model that estimates sales from TV, radio and newspaper advertising spend. This is my main individual project.

Overview

The project uses an advertising dataset of 200 records. TV, radio and newspaper spend are the inputs, and sales is the value the model estimates. I built it on my own.

My contribution

All of it. This was a solo project, and I did the following:

  • Explored and checked the data
  • Split it 80/20 into training and test sets
  • Fitted a multiple linear regression model with scikit-learn
  • Added an interaction feature combining TV and radio spend
  • Evaluated the model with MSE, RMSE and R²

Technologies

  • Python
  • pandas
  • NumPy
  • scikit-learn
  • Jupyter Notebook

Limits

The dataset is small, so this is a learning exercise, not a forecast I would rely on in the real world.
